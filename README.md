# idk-cool-game

Juego de parkour y plataformas de precisión inspirado en **Hollow Knight** y **Celeste**. Hecho con Godot.

## Jugar

Disponible en itch.io:

[https://crisnol.itch.io/idk-cool-game](https://crisnol.itch.io/idk-cool-game)

## Controles

| Acción | Tecla |
|---|---|
| Moverse | A / D o flechas izquierda / derecha |
| Saltar | Espacio, W o flecha arriba |

## Tecnología

- **Motor:** Godot Engine
